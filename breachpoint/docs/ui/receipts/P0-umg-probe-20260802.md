### All three WBPs are EMPTY. Correct parent class, zero widgets, no root.

- `ROADMAP.md:83-89`'s `[P]` hypothesis — *"An empty-but-correctly-parented WBP is exactly what an

### Failures recorded, because they were mine and they cost calls

C5a–C5d **failed on first attempt**: *"input param `instance` is required … but is missing"*. The
plan assumed `ObjectTools` used `object` / `properties`-as-dict / `property_names`. Real schema:

```
list_properties(instance)
get_properties (instance, properties: string[])
set_properties (instance, values: string)      ← values is a JSON STRING, not an object
delete         (path)                           ← not asset_path
```

**Property names are camelCase** (`layoutData`, `brushColor`), not C++ PascalCase. The toolset
warns names "CANNOT be guessed" and it is right — `list_properties` first is mandatory, and a wrong
name is where *"set_properties silently fails or sets the wrong property"* comes from.
